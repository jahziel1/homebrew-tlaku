# Homebrew tap for Tlaku

[Tlaku](https://github.com/jahziel1/tlaku) is free, open source (MIT) software for laser cutters and
engravers.

```sh
brew install --cask jahziel1/tlaku/tlaku
```

The app is not notarized by Apple yet; read the notes `brew` prints after installing.

---

**Español:** Tlaku es software libre (MIT) para cortadoras y grabadoras láser. Instálalo con
`brew install --cask jahziel1/tlaku/tlaku`. La app todavía no está notarizada por Apple; lee las
notas que muestra `brew` al terminar.

The cask lives in the main repository (`packaging/homebrew/`) and is copied here for each release.
